# 学军中学黑客松赛事系统（XJHACK Platform）

选手认领 + 邮箱验证码登录（免微信）+ 开放注册 + 资料自助 + 组队广场 + 队伍项目状态机 + 管理员后台。Node 22 内置 SQLite，**零原生编译依赖**，移动端优先（底部导航），支持局域网访问。

## 快速启动（本地）

```bash
npm install
cp .env.example .env        # 本地测试用默认配置即可
npm start                   # 打开 http://localhost:3000
```

开发模式（改代码自动重启）：`npm run dev`

服务启动后控制台会打印局域网地址（如 `http://192.168.31.155:3000`），同一 WiFi/局域网内手机可直接访问。

## 使用流程

### 双通道身份
- **认领名单**（首页）：真实报名选手网格（已去重；含「金熙林」模拟选手用于演示），搜索姓名/昵称/方向即时过滤；点卡片打开**详情弹窗**（大头像、方向、年级、标签、完整简介），简介/公告正文中的 **http(s) 链接自动识别为可点击跳转**，并在「链接」区提供**一键复制**；未认领选手详情内直接发起认领，已认领选手详情说明隐私保护与组队联系路径
- **认领**：点未认领卡片 → 确认 → 邮箱验证码登录即完成绑定，身份锁定（他人不可再认领）；认领后姓名锁定、信息可自助编辑
- **自由注册**：不在名单 → 注册参赛（邮箱验证码），创建自由选手身份，信息自助管理

详细步骤：
1. **已在名单？认领身份**：首页 → 认领名单里找到自己 → 点「认领」→ 二次确认 → 邮箱验证码登录绑定 → 身份锁定（姓名不可改）
2. **不在名单？开放注册**：登录页切「注册」Tab → 邮箱验证码 → 自动创建自由选手身份（姓名取邮箱前缀，可随时改）→ 登录后填资料
3. **邮箱登录**：输入邮箱 → 发送验证码 → 输码登录（默认 `MAIL_MODE=dev`，验证码打印在服务器控制台并回显在页面；正式部署改 `MAIL_MODE=resend` 或 `smtp`）
4. **管理员**：`.env` 的 `ADMIN_EMAILS` 中邮箱登录后自动获得权限，访问 `/admin.html` 管理赛程、公告、认领、选手、队伍

### 体验辅助
- **试验期体验登录**（`MAIL_MODE=dev` 时生效）：登录弹窗「认领身份」页底部有「⚡ 体验登录（金熙林）· 试验期」按钮，免邮箱一键以演示选手身份进入完整功能（资料编辑、组队广场、创建队伍等）；接口 `/api/demo/login` 仅 dev 模式可用，正式上线（改 `MAIL_MODE` 为 resend/smtp）自动失效
- **认领名单搜索**：首页搜索框按姓名 / 昵称 / 方向 / 标签即时过滤，快速定位自己；无结果时引导注册
- **首次使用引导**：注册 / 认领成功后弹出「下一步」引导（完善资料 / 去组队广场）
- **下拉刷新**：移动端页面顶端下拉 >70px 刷新全部数据（首页 + 组队 + 角标）
- **加载体验**：数据加载期间显示骨架屏占位；队伍进度条渲染时从 0 生长到目标百分比

### 组队与项目状态
- **组队广场** `/#teams`：仅展示小队列表（无杂项），顶部全宽「＋ 创建小队」按钮；**已在小队中（队长或成员）时按钮自动置灰锁定**（「✓ 已在小队中（创建锁定）」），未登录隐藏
- **创建小队**：方向改为**点选 chips**（开发/设计/产品/硬件/运营/教育/AI/其他 多选）；提供**项目灵感模板**（AI 应用/校园工具/数据可视化/硬件作品/游戏 Demo/内容创作）点击直接填入项目名；队名必填 + slogan + 简介 + 项目简介
- **个人资料技能标签**：交互式标签编辑器——绿色标签 chips 可点 × 删除、**＋** 号展开输入框自定义添加（回车/「完成」确认）、**快速添加模板**（Python/Go/C++/Java/前端/UI 设计/产品/运营/数据/AI/硬件/嵌入式/游戏/剪辑/摄影）一键点选，最多 10 个，保存为空格分隔字符串（兼容原格式）
- **创建队伍**：队长填写队名/口号/需要方向/项目名与描述 → 自动入队 → 广场出现
- **申请入队**：点队伍卡片 → 写留言 → 队长在「我的队伍」审批（接受/拒绝）；重复申请拦截，未通过前显示「等待队长」
- **申请结果即时反馈**：队长处理你的申请后，下次进入页面（或下拉刷新）自动提示「队长已接受 / 拒绝了你的申请」，不再被动等待
- **底部导航角标**：「组队」角标 = 你正在等待确认的申请数；「我的」角标 = 你队伍里待你审批的申请数
- **退出/解散**：成员可退出；队长可解散（解散后队伍不再出现在广场）
- **队伍项目状态机**（前后端一致）：

| 状态 | 进度 | 说明 |
|---|---|---|
| recruiting | 20% | 招募中 |
| formed | 40% | 已组队 |
| developing | 60% | 开发中 |
| submitted | 80% | 已提交 |
| judging | 90% | 评审中 |
| finished | 100% | 已结束 |
| disbanded | — | 已解散（隐藏） |

队长可在队伍详情里推进状态；管理员可在后台「队伍」Tab 修改任意队伍状态（解散需确认）。

### 「我的」
- 身份卡：显示认领/注册标记、姓名、方向、年级、简介、标签、头像（支持 8 张内置头像点选 + 自定义图片 URL）
- 编辑资料：认领选手姓名锁定、自由注册选手可改名；联系方式仅自己可见
- 我的队伍聚合：我创建的 / 我加入的 / 我申请的（待审批状态）

### 等待池（组队兜底）
- 组队截止后仍未组队的选手可一键进入**等待池**（组队页顶部入口卡片，仅登录且未组队时显示）
- 可附带一句备注（如「需要后端 / 想做 AI 应用」）；进入后可随时退出
- 公开接口只暴露等待人数；管理员在后台「等待池」Tab 看到全部等待者（姓名/方向/备注/时间），可**分配入队**（选目标队伍 → 加入并自动移出池）或手动**移除**
- 已在队伍中的选手进池会被拦截（400）

### 现场大屏 `/screen.html`
- 供开闭幕式 / 现场投屏使用：**4 页自动轮播**（15 秒/页，圆点可点，也可 `?page=0..3` 直接定位）
  - 总览：认领进度条（带过渡动画）、已认领/队伍数/等待池/进行中节点四大数字、方向分布
  - 参赛队伍：队伍墙（状态徽章 + 成员头像栈 + 项目名）
  - 赛程时间线：NOW 节点发光标记
  - 公告栏
- 顶部实时时钟（每秒刷新），数据 **60 秒自动重新拉取**；纯只读、无鉴权（不含任何联系方式，适合公开放映）

## 配置说明（.env）

| 变量 | 说明 |
|---|---|
| `PORT` | 端口，默认 3000 |
| `MAIL_MODE` | `dev`（控制台打印验证码）/ `resend`（Resend API）/ `smtp`（自建 SMTP） |
| `RESEND_API_KEY` | Resend 密钥（https://resend.com，月 3000 封免费） |
| `SMTP_HOST/USER/PASS/FROM` | 阿里云邮件推送 / 腾讯云 SES 等 SMTP 参数 |
| `ADMIN_EMAILS` | 管理员邮箱，逗号分隔 |

## 局域网 / 上线部署

**测试期（现在）**：本机 `npm start` 后，同网段手机访问控制台打印的局域网地址即可，无需任何配置。

**正式上线（国内合规路径）两条，任选其一：**

- **A. 扣子编程（Coze）托管（最快上线）**：本项目已支持**双模式数据层**（`server/store.js`）——本地无 `DATABASE_URL` 走 SQLite；扣子部署时平台注入 `DATABASE_URL`（PostgreSQL）即自动切换，首次启动自动从 `data/export.json` 导入真实数据（58 位选手 + 赛程/公告/队伍），无需手工建库。部署包 `deploy/xjhack-coze-deploy.zip`（含 `AGENTS.md` 给 AI 编程助手的说明），详细步骤见 `deploy/DEPLOYMENT_GUIDE.md`「1B」章节（含火山备案/免费 SSL/自检脚本）。扣子生产环境容器磁盘不持久，**必须**用 PostgreSQL 模式，勿用 SQLite 文件库。
- **B. 阿里云/腾讯云 轻量应用服务器（大陆节点）+ ICP 备案域名 + HTTPS + systemd（长期稳定）**：

```bash
# 服务器上（Ubuntu/Debian）
# 1) 上传项目到 /opt/xjhack（scp -r 或 git clone）
# 2) cp deploy/.env.production.example .env 并填写（ENC_KEY / 邮件 / ADMIN_EMAILS）
# 3) 一键部署
sudo bash deploy/deploy.sh
```

- **部署包在 `deploy/`**：`.env.production.example`（生产配置模板）、`xjhack.service`（systemd 服务）、`deploy.sh`（一键安装 Node 22 + 依赖 + 服务）、`DEPLOYMENT_GUIDE.md`（完整部署说明，含扣子与阿里云两条路径）
- 备案：域名 **ICP 备案**（主体建议学校/组委会名义），备案期间可用 `http://IP:3000` 临时访问
- HTTPS：备案通过后装 Nginx 反代 + Let's Encrypt 免费证书，配置强制跳转
- **联系方式加密存储**：生产环境必须设置 `ENC_KEY`（`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` 生成），服务端 AES-256-GCM 加密 `contact` 字段；未设置时开发模式按明文兼容并告警
- **数据合规**：服务器选大陆节点即数据不出境；已内置隐私政策页 `/privacy.html`、注册/认领同意勾选、选手「撤下我的资料」（PIPL 删除权入口，撤下后从公开名单消失）
- 方案 B 数据文件在 `data/xjhack.db`（SQLite，备份即复制该文件；`systemctl restart xjhack` 前先 `cp data/xjhack.db backup.db`）；方案 A 数据在扣子托管 PostgreSQL 中
- 数据量小（百人级），SQLite 完全够用，无需单独数据库服务
- 备选：腾讯云 CloudBase / 阿里云函数计算（需要换持久化数据库，不建议赛事场景）

## 隐私与数据合规（2026-09-30 新增）

- **隐私政策页** `/privacy.html`：收集项 / 用途 / 存储与保护 / 保留期限 / 选手权利 / 未成年人条款 / 联系方式
- **同意机制**：注册与认领（邮箱登录）前必须勾选「已阅读并同意《隐私政策》」，未勾选无法发送验证码
- **撤下资料（删除权入口）**：「我的」→「账号」→「撤下我的资料」，立即从主页认领名单消失，可随时恢复
- **联系方式加密**：服务端 AES-256-GCM（`ENC_KEY`），仅本人与管理员后台可见明文；公开接口不返回
- **数据不出境**：部署在大陆节点（见上文部署章节）

## 安全说明

- 邮箱验证码 10 分钟有效、5 次错误锁定、一次性使用
- **发送限流**：同一邮箱 60 秒内 1 封、同一 IP 60 秒内 5 封，超限返回 429「发送太频繁」（防刷邮件/爆破验证码）
- **会话有效期 30 天**：登录会话超期自动失效（`sessions.created_at + 30 days`）
- 认领校验比对报名时登记的微信号，防止冒领；认领后姓名锁定，管理员可撤销
- 微信号/联系方式不对外展示（隐私收敛）；页脚已加选手信息撤回声明
- 管理员账号登录不创建选手身份（避免后台出现"幽灵选手"）
