# 学军中学黑客松赛事系统（XJHACK Platform）

学军首届黑客松全栈赛事平台：认领身份 / 开放注册 → 邮箱验证码 + 密码登录（免微信）→ 资料自助管理（标签 / 简介 / 方向多选 / 性别 / 联系方式）→ 组队广场（申请 + 队长主动招募双向匹配）→ 队伍项目状态机 → 等待池 → 管理员后台。Node 22 内置 SQLite，**零原生编译依赖**，移动端优先（底部导航），暗色霓虹视觉。

已正式上线：**http://47.76.118.161/**（阿里云香港轻量，systemd 托管）。

## 快速启动（本地）

```bash
npm install
cp .env.example .env        # 本地测试用默认配置即可
npm start                   # 打开 http://localhost:3000
```

开发模式（改代码自动重启）：`npm run dev`

服务启动后控制台会打印局域网地址（如 `http://192.168.31.155:3000`），同一 WiFi/局域网内手机可直接访问。

## 使用流程

### 双通道身份
- **认领名单**（首页）：真实报名选手网格（已去重；演示账号不参与展示），搜索姓名/昵称/方向即时过滤；点卡片打开**详情弹窗**（大头像、方向、年级、性别、标签、完整简介），简介/公告正文中的 **http(s) 链接自动识别为可点击跳转**，并在一键复制区展示；未认领选手详情内直接发起认领
- **认领**：点未认领卡片 → 确认 → 邮箱验证码登录即完成绑定，身份锁定（他人不可再认领）；认领后姓名锁定、信息可自助编辑
- **自由注册**：不在名单 → 注册参赛（邮箱验证码），创建自由选手身份，信息自助管理

详细步骤：
1. **已在名单？认领身份**：首页 → 认领名单里找到自己 → 点「认领」→ 二次确认 → 邮箱验证码登录绑定 → 身份锁定（姓名不可改）
2. **不在名单？开放注册**：登录页切「注册」Tab → 邮箱验证码 → 自动创建自由选手身份（姓名取邮箱前缀，可随时改）→ 登录后填资料
3. **登录方式**：首次登录发送邮箱验证码；**首次登录必须设置密码（两次确认）**，之后可用「密码登录」；密码忘记可走邮箱验证码重进后重设
4. **管理员**：访问 `/admin.html` 用**管理员独立密码**登录（密码由组委会掌握，不与选手邮箱体系混用），管理赛程、公告、认领、选手（含身份/性别）、队伍（含项目状态）、等待池、点赞统计

### 身份机制（评委 / 观察员）
- 默认身份为**参赛选手**；管理员可在后台为选手设置「评委 / 观察员」身份
- 评委与观察员**不出现在选手公开列表 / 认领名单**中，可正常登录查看赛程与公告
- 组队相关能力仅参赛选手可用（后端守卫拦截）

### 点赞与浏览（社交）
- **顶部点赞**：首页顶部点赞按钮，**无需登录**即可点赞，每人每天最多 5 次，达到上限不额外提示
- **头像点赞**：每位选手卡片 / 详情可点赞，每人每天对同一位选手最多 1 次；点赞数实时展示在卡片与详情页
- **好友机制**：两人**互相点赞**即成为好友，双方卡片上显示 💛 好友标记
- **浏览统计**：首页与选手资料被查看次数以图标 + 数字展示（无需文字）

### 组队与项目状态
- **组队广场** `/#teams`：仅展示小队列表，顶部全宽「＋ 创建小队」按钮；**已在小队中（队长或成员）时按钮自动置灰锁定**，未登录隐藏
- **创建小队**：方向点选 chips（开发/设计/产品/硬件/运营/教育/AI/其他 **多选**）；提供**项目灵感模板**（AI 应用/校园工具/数据可视化/硬件作品/游戏 Demo/内容创作）；队名必填 + slogan + 简介 + 项目简介
- **组队规则（硬约束，前后端双校验，2026-10-01 按大赛 Q&A 要求更新）**：
  - **每队 2~4 人**：最多 4 人（申请/招募/接受全链路拦截）；提交作品时**强制至少 2 人**，单人无法提交
  - **作品提交（submitted）后不再接受加入**：submitted / judging / finished 队伍申请与招募均被拦截
  - 每人同时只属于**一支队伍**：队长需解散队伍才能加入其他队伍；成员需退出才能申请他队或建队
  - **队长不能申请加入其他队伍**，也不能再次创建队伍
  - 每人**最多同时申请 3 支队伍**（待队长审批）；某条申请**通过后，其余 pending 申请自动作废**
  - 「我的」页的申请列表每条可**撤销**（二次确认），撤销即释放名额
- **申请入队**：点队伍卡片 → 写留言 → 队长在「我的队伍」审批（接受/拒绝）；重复申请、满额、已在队均拦截并提示原因
- **队长主动招募**：选手详情页「🤝 招募进我的队伍」→ 填留言发出邀请 → 被招募者在「我的」页看到邀请卡片（队伍名/队长/留言），**接受即入队**（其 pending 申请与其余邀请自动作废）或拒绝；已入队者不可被招募
- **队伍分享**：队伍详情弹窗「↗ 分享队伍」→ 生成暗色霓虹招募卡片（队徽/队名/状态/项目/需求/成员，底部带网址）→ 保存到相册，发群/朋友圈即传播
- **底部导航角标**：「组队」角标 = 你正在等待确认的申请数；「我的」角标 = 你队伍里待你审批的申请数
- **退出/解散**：成员可退出、队长可解散（解散后队伍不再出现在广场）；退出/解散/撤下资料等**取消类操作均有二次确认**
- **队伍项目状态机**（前后端一致，队长在队伍详情推进，管理员后台可改）：

| 状态 | 进度 | 说明 |
|---|---|---|
| recruiting | 20% | 招募中 |
| formed | 40% | 已组队 |
| developing | 60% | 开发中 |
| submitted | 80% | 已提交 |
| judging | 90% | 评审中 |
| finished | 100% | 已结束 |
| disbanded | — | 已解散（隐藏） |

### 「我的」
- 身份卡：姓名、方向（多选）、年级、性别（**默认保密，不显示任何图标**；选男 ♂ / 女 ♀ 后展示对应彩色图标）、简介、技能标签、头像（支持系统头像点选 + **相册/自定义图片上传**，自动压缩）
- **技能标签**：交互式标签编辑器——绿色标签 chips 可点 × 删除、＋ 展开输入框自定义添加（回车/「完成」确认）、**快速添加模板**（Python/Go/C++/Java/前端/UI 设计/产品/运营/数据/AI/硬件/嵌入式/游戏/剪辑/摄影）一键点选，最多 10 个
- **联系方式（登录后可见）**：编辑提示「微信 / 手机 / 邮箱 / 其他」；登录用户查看任意公开选手详情可一键复制其联系方式；撤下资料后不再展示
- **分享名片**：「编辑资料」下方「↗ 分享名片」→ 生成个人名片图（头像/姓名/方向/年级/标签/简介，底部带首页网址）→ 保存到相册
- **我的队伍聚合**：我创建的 / 我加入的 / 我申请的（可撤销）/ 收到的招募邀请（可接受/拒绝）
- **撤下我的资料**：账号区一键撤下，立即从公开名单消失（PIPL 删除权入口），可随时恢复

### 等待池（组队兜底）
- 组队截止后仍未组队的选手可一键进入**等待池**（组队页顶部入口，仅登录且未组队时显示）
- 可附带一句备注；进入后可随时退出；已在队伍中的选手进池会被拦截
- 公开接口只暴露等待人数；管理员后台可看到全部等待者（姓名/方向/备注/时间），可**分配入队**或手动**移除**

### 现场大屏 `/screen.html`
- 供开闭幕式 / 现场投屏使用：**4 页自动轮播**（15 秒/页，圆点可点，也可 `?page=0..3` 直接定位）
  - 总览：认领进度条、已认领/队伍数/等待池/进行中节点四大数字、方向分布
  - 参赛队伍：队伍墙（状态徽章 + 成员头像栈 + 项目名）
  - 赛程时间线：NOW 节点发光标记
  - 公告栏
- 顶部实时时钟，数据 **60 秒自动重新拉取**；纯只读、无鉴权（不含联系方式，适合公开放映）

## 配置说明（.env）

| 变量 | 说明 |
|---|---|
| `PORT` | 端口，默认 3000 |
| `DATABASE_URL` | 设置则走 PostgreSQL（扣子托管用）；本地不设走 SQLite |
| `MAIL_MODE` | `dev`（控制台打印验证码）/ `resend`（Resend API）/ `smtp`（自建 SMTP） |
| `SMTP_HOST/USER/PASS/FROM` | SMTP 发信参数（线上已配置 QQ 邮箱 smtp） |
| `ADMIN_EMAILS` | 管理员邮箱（逗号分隔，验证码登录后获后台权限） |
| `ADMIN_PASSWORD` | 管理员独立密码（/admin.html 登录用，生产必配） |
| `ENC_KEY` | 联系方式 AES-256-GCM 加密密钥（64 位 hex，生产必配） |

（微信登录已确认不需要，`WECHAT_*` 相关代码保留但无入口）

## 部署

**当前生产**：阿里云轻量应用服务器（香港）47.76.118.161，systemd 服务 `xjhack`，代码 `/opt/xjhack`，SQLite 库 `/opt/xjhack/data/xjhack.db`，SMTP 发信已生效（真实验证码送达）。

- 部署包在 `deploy/`：`.env.production.example`（生产配置模板）、`xjhack.service`（systemd）、`deploy.sh`（一键安装 Node 22 + 依赖 + 服务）、`DEPLOYMENT_GUIDE.md`（扣子与阿里云两条路径完整说明）
- 更新代码：上传 server/*.js → `chown xjhack:xjhack` + `systemctl restart xjhack`；public 静态文件 chown 即生效
- 数据备份：复制 `data/xjhack.db`（重启前建议先 `cp data/xjhack.db backup.db`）
- 数据量小（百人级），SQLite 完全够用；若走扣子托管则用 PostgreSQL 模式（`DATABASE_URL` 注入自动切换，首次启动自动从 `data/export.json` 导入真实数据）
- 域名 + HTTPS：大陆节点需 ICP 备案，备案通过后 Nginx 反代 + Let's Encrypt 免费证书

## 隐私与数据合规

- **隐私政策页** `/privacy.html`：收集项 / 用途 / 存储与保护 / 保留期限 / 选手权利 / 未成年人条款 / 联系方式
- **同意机制**：注册与认领（邮箱登录）前必须勾选「已阅读并同意《隐私政策》」
- **撤下资料（删除权入口）**：「我的」→「账号」→「撤下我的资料」，立即从公开名单消失，可随时恢复
- **联系方式加密**：服务端 AES-256-GCM（`ENC_KEY`）；仅登录选手可见，公开接口对未登录返回空
- **数据不出境**：正式合规路径建议大陆节点 + 备案；当前香港节点为轻量试验部署
- **发布前清理**：演示账号（金熙林 / 回响Bot）在正式发布时删除，不留任何痕迹

## 安全说明

- 邮箱验证码 10 分钟有效、5 次错误锁定、一次性使用；发送限流（同邮箱 60s 1 封、同 IP 60s 5 封）
- **密码登录**：首登设密码（二次确认，bcrypt 哈希存储）；密码登录与验证码登录双通道
- **单会话锁定**：同一账号同一时刻仅一个会话，新登录会踢出旧会话
- 会话有效期 30 天；管理员独立密码登录（不创建选手身份，避免后台"幽灵选手"）
- 认领后姓名锁定防冒领，管理员可撤销；组队/申请/招募均有后端守卫（队长限制、3 条上限、入队拦截）
- 取消类操作（退出 / 解散 / 撤下 / 撤销）全部二次确认防手误
